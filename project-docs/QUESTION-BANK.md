# 题库结构模型与出题策略

> v0.13.0 起生效。本文回答三个问题：题库从哪来、题目怎么组织、每轮怎么出题。

## 一、题库来源与边界

| 来源 | 可用性 | 说明 |
|---|---|---|
| 义务教育课程标准（2022 版） | 可引用 | 学段目标、知识领域划分、能力要求，是锚点设计的依据 |
| 统编教材目录 / 单元目标 | 可引用 | 只取「学什么、到什么程度」，不复制课文与习题 |
| 教材原文、教辅、真题 | 不可复制 | 有版权，且直接搬运会破坏离线产品的可控性 |
| 公开在线题库 | 谨慎 | 质量参差、答案错误率高、授权不清，只作参考不作数据源 |

结论：**按课标自建 + 抽样审核**。题目由内容生成规范约束、脚本校验、人工抽审三道关，产物是本地 CSV 内容包，随 APK 发版，完全离线。

## 二、五层结构模型

```
学段 Stage（KG / PRIMARY_LOW）
  └─ 领域 Domain（数与代数 / 图形与几何 / 语言与阅读）
       └─ 主题 Topic（18 个知识板块）
            └─ 锚点 Anchor（55 个可观察能力单元）
                 └─ 题目 Item（每题带 6 类标签）
```

- **主题**是给家长看的板块，如「拼音启蒙」「10 以内加减」「元角分换算」。
- **锚点**是可观察、可测评、可干预的最小能力单元，必须能写成「看到什么算过」。
- 每个锚点在**记忆 / 理解 / 应用**三个认知层级上独立记录掌握状态。

## 三、题目标签体系

每道题固定 6 类标签：

| 字段 | 取值 | 作用 |
|---|---|---|
| `anchorCode` | 锚点编码 | 归属哪个能力单元；组卷的主索引 |
| `cognitiveLevel` | MEMORY / UNDERSTANDING / APPLICATION | 记忆 / 理解 / 应用，决定当前该练哪一层 |
| `variantType` | TEXT / DIAGRAM / CONTEXT / EXPRESSION | 文字 / 图示 / 情境 / 算式，迁移题靠它换表征 |
| `difficulty` | 1–5 | 诊断题取最易，目标题取接近 3，迁移题取偏难 |
| `tags` | 中文短语（顿号分隔） | 形近字、易错、高频等，供检索与专项练习 |
| `stage` | KG / PRIMARY_LOW | 学段隔离，切孩子自动换题库 |

## 四、出题策略

每轮只推 3 题，不是随机抽题，而是三步决策。

**第一步：选板块**
- 统计每个主题下所有锚点是否都已稳固；未稳固的必修板块优先；
- 已稳固的板块整体降权，避免连续多轮只在同一个板块打转。

**第二步：选锚点**
- 过滤前置锚点未达标的项（前置概率 < 0.6 且未稳固则暂不推进）；
- 在最近发展区（掌握概率 0.55–0.85）内按「板块是否已稳固 → 掌握概率」排序；
- 取排序最靠前的一个锚点，再取它第一个未稳固的认知层级。

**第三步：组卷**
1. 排除冷却期内做过的题（幼儿园 3 天、小学 7 天）；
2. 诊断题：最容易的一题，用来确认基础；
3. 目标题：难度最接近 3 的一题，当前层级的主攻题；
4. 迁移题：优先换一种表征方式，验证是否真正理解；
5. 新鲜题不足 3 道时才放宽冷却限制兜底，保证一轮能做完。

## 五、家长看到什么

「学习报告 → 能力地图」按主题展示：

- 主题卡片：`必修 x/y · 已稳固 x/y · 所属领域` + 进度条；
- 点开主题：每个锚点显示记忆 / 理解 / 应用三档状态（已稳固 / 攻坚中 / 未触发）；
- 不暴露小数概率，避免家长对模型数字产生误解；
- 首页「今天的挑战」同时显示主题名，家长和孩子对得上今天练的是什么。

## 六、内容包加工流程

```
content-packs/SPEC.md       内容生成规范（15 列 CSV、标签、表征、审校要求）
        ↓
content-packs/pack*.csv     分包生成（按主题分组，每锚点 8–10 题）
        ↓
content-packs/validate.py   校验：列数、锚点合法性、学段一致、选择题答案、题干去重
        ↓
questions_v2.csv            合并产物
        ↓
app/src/main/assets/        随 APK 发版
        ↓
AnchorSeeder                 启动时按题干去重增量导入，老题就地升级标注
```

校验项：每行 15 列、锚点必须存在、subject/stage 与锚点一致、认知层级与表征合法、选择题答案必须在选项内、全库题干唯一。

## 七、如何继续扩题

1. 在 `content-packs/` 新建 `pack7_*.csv`，表头与 SPEC.md 一致；
2. 锚点编码只能取自现有 55 个；新能力先在 `AnchorCatalog.kt` 定义锚点与主题；
3. 运行 `python3 content-packs/validate.py`，问题清零后 `--merge`；
4. 复制到 `app/src/main/assets/questions_v2.csv`，升版本发版即可。

> 题库是产品卖点，扩题优先补「每锚点的应用层」和「同锚点的不同表征」，而不是同题型换数字。
