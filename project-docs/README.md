# 小步 · LoopLearning

> 一个把 **Loop Engineering（闭环工程）** 落到产品端的端侧伴学引擎与 Android App。
> 面向幼小衔接与小学低年级（约 4–8 岁），不题海、不按分数分层，让孩子在「精炼测评 → 诊断 → 精准改进 → 即时激励 → 再测评」的循环里按自己的节奏进步。

- **当前版本**：v0.16.0
- **平台**：Android 手机 / 平板（本地优先，无服务器依赖）
- **适用人群**：幼小衔接 + 小学低年级（1–2 年级），不预设成绩起点
- **内容范围**：当前覆盖语文、数学基础能力；题库的「领域 → 主题 → 锚点」结构可扩展到常识、科学素养、儿童心理成长等通识板块
- **题库规模**：18 个主题、61 个锚点、584 道带标签题目
- **文档维护**：本目录即项目唯一事实来源，每次迭代更新 CHANGELOG

---

## 一、项目目标

1. 验证 Loop Engineering 在**自主优化类产品**中的端到端落地能力；
2. 用精益商业画布论证该产品的商业价值与成本结构；
3. 交付一个可安装、可演示、可持续迭代的 Android MVP。

## 二、业务场景与角色

| 角色 | 画像 | 核心诉求 |
|---|---|---|
| 买家 | 双职工父母、关注通识启蒙的家庭，长期加班，无暇辅导 | 有人盯、看得见进步、别让孩子掉队 |
| 主用户 | 幼小衔接 / 小学低年级孩子，起点不限（刚起步、稳步巩固或学有余力） | 题目少一点、别被否定、有成就感 |
| 次用户 | 家长 | 看清薄弱点、拿到可执行的干预建议 |

**产品承诺**：不按分数设门槛；会做的题减负，不会的题才练；永远先保护积极性与自尊心。

## 三、MVP 功能清单（v0.16.0）

### 孩子端
- 12 题摸底测评：跨板块取样，摸清当前处于幼小衔接、一年级还是二年级水平
- 精炼测评：每轮 8 题，先错题、再薄弱知识点、最后补足难度梯度
- 年级阶梯：不拆题库，一年级达标后自动优先推二年级内容，简单题不再反复占用时间
- 三态即时反馈：完全正确 / 思路接近 / 未掌握，**答错不扣分**
- 错题三级闭环：重做 → 变形 → 延伸，掌握度 ≥80 自动移出错题本
- 星星激励：答对 1 颗、难题 +1、连对 3 题 +1、突破一层 +3，全部是孩子数得清的个位数
- 奖励商城：用星星兑换家长配置的心愿（5–30 颗，零花钱、游戏时间等）
- 多孩子切换：学习记录、错题、积分、掌握度完全隔离

### 家长端（4 位数字密码保护）
- 学习报告：总体掌握度、错题数、薄弱点雷达、近 7 天正确率、近 4 周汇总
- 干预建议：基于薄弱点的本地规则生成，后续接入 LLM
- 手工发星：+1 / +2 / +5 / -1 快捷操作，需填写原因，写入星星流水
- 版本更新记录：按版本倒序查阅每版改了什么，离线可查
- 孩子管理：新增 / 编辑 / 删除 / 切换
- 奖励管理：自定义奖励项，支持上下架
- 锚点认知测评：记忆 / 理解 / 应用三层独立掌握度，今日只练最该补的那一层，最多 3 题
- 当前水平：显示一年级 / 二年级必修锚点进度与下一步建议
- 题目质量自动排除：偏难 / 疑似秒答的题默认不进组卷，可关闭，支持单题停用 / 恢复
- 家长密码：首次设置，之后每次进入家长区校验，回首页即失效
- 题库管理：列表搜索、单题修正、启停、CSV 导入导出（可在飞书表格编辑题库）
- 数据备份：全量导出 JSON / 导入恢复，换机重装不丢数据
- 隐私政策：App 内可读，说明本地数据边界、采集字段与关闭方式
- 首次启动隐私选择：同意后才采集；可选「仅本地使用」，拒绝不影响任何功能
- 匿名使用统计：仅上报启动 / 日打开 / 练习完成 / 测评完成 4 类事件，同意后开启、可随时关闭

## 四、商业模式（Lean Canvas 摘要）

| 模块 | 内容 |
|---|---|
| Problem | 双职工无暇辅导；题海战术损伤自信；传统教培 App 同质化为刷题工具 |
| Solution | 少题精测 + 错题闭环 + 积分激励 + 家长报告与干预建议 |
| UVP | 「不题海，让孩子自信地进步」 |
| Customer | 买家：无时间辅导的职工父母；用户：4–8 岁儿童（幼小衔接至小学低年级） |
| Metrics | 北极星：周进步率；辅：错题重做率、测评完成率、家长干预采纳率 |
| Channels | 视频号趣味题引流 → APK 下载；宝妈社群 |
| Cost Structure | 本地 Room 存储，无服务器；LLM 仅用于报告生成，MVP 月成本 < ¥500 |
| Revenue | 免费版 + ¥99/月订阅 + 视频号内容变现 |
| Unfair Advantage | 数据飞轮（越用越准）+ 本地优先零边际成本 + 教育心理学设计 |

完整画布见仓库内 `lean-canvas/lean-canvas.html`。

## 九、构建、混淆与统计配置

匿名统计端点不硬编码，通过构建参数注入：

```bash
gradle :app:assembleRelease \
  -PtelemetryWebhook="https://open.feishu.cn/open-apis/bot/v2/hook/你的Webhook" \
  -Pchannel="feishu"
```

- 不传 `-PtelemetryWebhook` 时 App 不发送任何统计数据（等价全局关闭）；
- 只接受 `https://` 地址，构建期校验，避免明文传输；
- `-Pchannel` 默认 `dev`，用于区分分发渠道；
- 飞书多维表格侧配置「自动化 → 接收到 Webhook 请求 → 新增记录」，按 `event` / `install_id` / `version` / `channel` / `stage` / `ts` 建列即可；
- 完整字段清单、不采集内容与数据保留策略见 `PRIVACY.md`，威胁模型见 `SECURITY.md`。

### 9.1 Release 混淆与资源裁剪

release 构建默认开启 R8（`isMinifyEnabled = true`）与 `shrinkResources`，规则见 `app/proguard-rules.pro`。
构建后请私人留存 `app/build/outputs/mapping/release/mapping.txt`，用于解读崩溃堆栈，不要上传到公开仓库。

### 9.2 Release 签名（不上传密钥）

在 `android-app/keystore.properties` 中配置（该文件已被 `.gitignore` 忽略）：

```properties
storeFile=/绝对路径/xiaobu-release.jks
storePassword=***
keyAlias=xiaobu
keyPassword=***
```

没有该文件时 release 仍可构建，但产物未签名、不能直接安装或上架。
keystore 与密码建议同时保存在密码管理器中，丢失后无法给已安装用户推送更新。
