# 变更日志 CHANGELOG

本项目遵循 [语义化版本](https://semver.org/lang/zh-CN/)：`主版本.次版本.修订号`。
MVP 阶段统一 `0.x.y`，正式发布后升级为 `1.0.0`。

## 版本管理约定

### 发布渠道

安装包同时发布到**飞书项目文件夹与 GitHub Releases**。聊天交付只发送可访问的 HTTPS 地址，不使用仅在沙箱有效的 `computer://` 本地路径；外部下载优先提供 GitHub Release，飞书文件用于项目内归档与协作。

| 内容 | 发布位置 | 命名规范 |
|---|---|---|
| 安装包 | 飞书 `智能伴学-LoopLearning/dist/` + GitHub Releases | `LearningLoop-v{版本}.apk` |
| 源码包 | 飞书 `智能伴学-LoopLearning/src/` | `LearningLoop-src-v{版本}.zip` |
| 项目文档 | 飞书项目文件夹 + 仓库 `project-docs/` | `README.md` / `ARCHITECTURE.md` / `CHANGELOG.md` |
| 项目管理 | [飞书项目管理与版本规划](https://my.feishu.cn/docx/UviHdb60Ho4Rz7xUBFAcjisi6Pg) | 当前进度、发布结果、风险与后续版本候选 |

- 开源仓库：[GitHub](https://github.com/BrownQin/xiaobu-loop) · [Gitee](https://gitee.com/nmd568/xiaobu-loop)
- 项目文件夹：[智能伴学-LoopLearning](https://my.feishu.cn/drive/folder/Em56fTdn9ldDY4dwzi4c82mD6Wc)

### 版本号规则

| 位 | 何时递增 | 示例 |
|---|---|---|
| 次版本 `x` | 新增功能、数据模型变更、交互重构 | 0.3.0 → 0.4.0 |
| 修订号 `y` | 仅修复缺陷、文案与样式微调 | 0.4.0 → 0.4.1 |

### 每次发版固定动作

1. 代码合入，并通过 `gradle :app:testDebugUnitTest :app:assembleRelease`；
2. 更新本文件新增版本段落，同步 `README.md` 版本总表和 App 内 `VersionHistory`；
3. 打包源码 `src/LearningLoop-src-v{版本}.zip`（排除 `build/`、`.gradle/`、`local.properties`）；
4. 上传 APK 到飞书 `dist/` 和对应 GitHub Release，源码包上传到飞书 `src/`；
5. 记录 SHA-256 与 HTTPS 下载地址，并更新飞书项目管理文档；
6. 同名覆盖升级时使用飞书文件版本历史（`drive +version-history` 查看、`+version-revert` 回滚）；
7. 聊天只交付 HTTPS 链接，交付后实际下载并核验安装包，不发送 `computer://` 本地路径。

### 历史版本留存

- 飞书 `dist/` 与 GitHub Releases 保留每个版本的 APK，不删除旧版本；
- 若需覆盖同名文件，先确认旧版本已在 `dist/` 有独立版本号存档；
- 飞书原生文件历史作为第二层兜底。

## v0.14.0 — 2026-11-14

### 新增（摸底测评）
- 新增 12 题摸底测评：跨板块取样（小学 10 个主题各 1 题 + 2 道补足），优先取最低年级锚点的记忆 / 理解层，忽略冷却期。
- 新孩子首次进入首页会看到测评入口；家长可在「管理 → 重新测评」随时重测。
- 测评结束展示当前年级结论与下一步建议，普通练习不显示。

### 新增（年级阶梯）
- 不再拆分一年级 / 二年级题库：用锚点年级 + 阶梯判定，一年级必修锚点稳固率 ≥ 80% 即判定「已达到一年级水平」，之后优先推送二年级锚点。
- 已稳固的简单锚点由最近发展区（0.55–0.85）与冷却期自然跳过，不额外占用测评时间。
- 新增 6 个一年级锚点与 60 道配套题（20 以内进退位、20 以内应用题、100 以内数的认识、图形分类、整时半时、人民币），题库增至 584 题。
- 学习报告新增「当前水平」卡片，显示一年级 / 二年级必修锚点进度与下一步建议；首页问候显示当前水平。

### 新增（题目质量闭环）
- 「自动排除」默认开启：样本 ≥ 15 时，正确率 ≤ 15% 判为偏难、秒答占比 ≥ 60% 判为疑似秒答，这两类题不再进入组卷；家长可在「题目质量」页关闭。
- 质量结论写入 `question.quality_state`（数据库 v8 迁移），组卷查询统一过滤。
- 题目质量看板支持单题停用 / 恢复，并标注「已自动排除，不进入组卷」。

### 数据
- 数据库版本 v7 → v8：`question` 新增 `quality_state TEXT NOT NULL DEFAULT ''`。

## v0.13.0 — 2026-11-14

### 新增（题库结构模型）
- 题库从「知识点平铺」重构为五层模型：**学段 Stage → 领域 Domain → 主题 Topic → 锚点 Anchor → 题目 Item**。
- 18 个知识板块（幼儿园 8 个、二年级 10 个），55 个可观察锚点，每个锚点内再分记忆 / 理解 / 应用三层。
- 内置题库扩容到 **524 道锚点题**：每题带锚点、认知层级、表征方式（文字 / 图示 / 情境 / 算式）、标签，随 APK 内置 `assets/questions_v2.csv`。
- 相关文档：《题库结构模型与出题策略》。

### 新增（出题策略）
- 三步选点：先选板块（必修未稳固优先、避免同一板块连续打转）→ 再选锚点（前置达标 + 最近发展区 0.55–0.85）→ 最后组卷。
- 组卷三档：诊断题（最易）→ 目标题（难度居中）→ 迁移题（换表征），一题一档，覆盖不同表征。
- 冷却期：幼儿园 3 天、小学 7 天内做过的题不再重复出现（准入门槛：同锚点新鲜题不足时才放宽）。

### 变更
- 家长「学习报告」中的锚点矩阵升级为**能力地图**：先给主题概览（必修完成度 / 已稳固比例 / 所属领域），点开主题再看锚点 × 三层状态。
- 首页「今天的挑战」显示所属主题，家长和孩子都能看清今天练的是哪个板块。

### 数据
- 启动时按题干去重增量导入内容包；老库里的同题干题目若未标注锚点，就地升级标注，保留题目 id 与启停状态。
- 无数据库结构变更，升级不丢历史数据。
