# 变更日志 CHANGELOG

本项目遵循 [语义化版本](https://semver.org/lang/zh-CN/)：`主版本.次版本.修订号`。
MVP 阶段统一 `0.x.y`，正式发布后升级为 `1.0.0`。

## 版本管理约定

### 唯一发布渠道

所有安装包**只发布到飞书云空间**，不再通过聊天工具、临时网盘或本地目录分发，避免版本错乱。

| 内容 | 飞书位置 | 命名规范 |
|---|---|---|
| 安装包 | `智能伴学-LoopLearning/dist/` | `LearningLoop-v{版本}.apk` |
| 源码包 | `智能伴学-LoopLearning/src/` | `LearningLoop-src-v{版本}.zip` |
| 项目文档 | `智能伴学-LoopLearning/` 根目录 | `README.md` / `ARCHITECTURE.md` / `CHANGELOG.md` |

项目文件夹：[智能伴学-LoopLearning](https://my.feishu.cn/drive/folder/Em56fTdn9ldDY4dwzi4c82mD6Wc)

### 版本号规则

| 位 | 何时递增 | 示例 |
|---|---|---|
| 次版本 `x` | 新增功能、数据模型变更、交互重构 | 0.3.0 → 0.4.0 |
| 修订号 `y` | 仅修复缺陷、文案与样式微调 | 0.4.0 → 0.4.1 |

### 每次发版固定动作

1. 代码合入并编译通过（`gradle :app:assembleDebug`）；
2. 更新本文件新增版本段落 + 同步 `README.md` 版本总表；
3. 打包源码 `src/LearningLoop-src-v{版本}.zip`（排除 `build/`、`.gradle/`、`local.properties`）；
4. 上传 APK 到 `dist/`、源码到 `src/`；
5. 记录 SHA-256；
6. 同名覆盖升级时使用飞书文件版本历史（`drive +version-history` 查看、`+version-revert` 回滚）。

### 历史版本留存

- `dist/` 保留每个版本的 APK，不删除旧版本；
- 若需覆盖同名文件，先确认旧版本已在 `dist/` 有独立版本号存档；
- 飞书原生文件历史作为第二层兜底。

## v0.13.0 — 2026-11-14

### 新增（题库结构模型）
- 题库从「知识点平铺」重构为五层模型：**学段 Stage → 领域 Domain → 主题 Topic → 锚点 Anchor → 题目 Item**。
- 18 个知识板块（幼儿园 8 个、二年级 10 个），55 个可观察锚点，每个锚点内再分记忆 / 理解 / 应用三层。
- 内置题库扩容到 **524 道锚点题**：每题带锚点、认知层级、表征方式（文字 / 图示 / 情境 / 算式）、标签，随 APK 内置 `assets/questions_v2.csv`。
- 相关文档：《题库结构模型与出题策略》。

### 新增（出题策略）
- 三步选点：先选板块（必修未稳固优先、避免同一板块连续打转）→ 再选锚点（前置达标 + 最近发展区 0.55–0.85）→ 最后组卷。
- 组卷三档：诊断题（最易）→ 目标题（难度居中）→ 迁移题（换表征），一题一档，覆盖不同表征。
- 冷却期：幼儿园 3 天、小学 7 天内做过的题不再重复出现（准入门槛：同锚点新鲜题不足时才放宽）。

### 变更
- 家长「学习报告」中的锚点矩阵升级为**能力地图**：先给主题概览（必修完成度 / 已稳固比例 / 所属领域），点开主题再看锚点 × 三层状态。
- 首页「今天的挑战」显示所属主题，家长和孩子都能看清今天练的是哪个板块。

### 数据
- 启动时按题干去重增量导入内容包；老库里的同题干题目若未标注锚点，就地升级标注，保留题目 id 与启停状态。
- 无数据库结构变更，升级不丢历史数据。
