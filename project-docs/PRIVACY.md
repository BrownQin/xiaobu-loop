# 小步隐私政策

- 生效日期：2026-11-14
- 适用版本：0.17.0 及以上
- 维护者：小步个人开发者
- 联系方式：GitHub Issues（<https://github.com/BrownQin/xiaobu-loop/issues>）
- 开发者主体与工作邮箱：上架前由开发者补充（不使用私人手机号）

小步是一个本地优先的伴学 App。我们把「孩子学习数据留在你手里」当作默认设计，而不是一项可选设置。本政策说明我们到底会处理哪些信息、为什么处理、以及你如何随时收回授权。

---

## 一、本地优先：绝大多数数据不出设备

以下内容**只保存在你的手机或平板的本地数据库**，不会上传到任何服务器：

- 孩子档案：昵称、头像、年级、学段
- 题库、题目启停状态、题目质量结论
- 每次作答的记录：对错、耗时、改答次数、选项切换次数、信号质量
- 错题本、掌握度、锚点状态、学习报告
- 星星明细、奖励设置、兑换记录

只有在你主动操作时，这些数据才会以文件形式离开设备：

1. 家长导出「数据备份」或「导出诊断日志」；
2. 家长导出题库 CSV。

卸载 App 或在系统中「清除数据」，本地数据库即被删除，我们无法恢复，也无法读取。

## 二、匿名使用统计（默认开启，可随时关闭）

为了判断每个版本是否真的被使用、有没有人卡在启动或测评环节，小步会向开发者配置的接收端点发送**事件级**匿名数据。

首次打开直接进入学习，不在首屏弹出隐私确认。最小化匿名统计默认开启；家长可在 App 内隐私政策页随时关闭，关闭不影响任何学习功能。

### 2.1 采集字段（全部字段）

| 字段 | 含义 | 示例 |
|---|---|---|
| `event` | 事件名 | `activate` / `day_open` / `quiz_done` / `diagnostic_done` |
| `install_id` | 安装时本地随机生成的 UUID | `7d3f1c2a-…` |
| `version` | App 版本号 | `0.15.0` |
| `channel` | 分发渠道标识 | `dev` / `feishu` |
| `stage` | 孩子所在学段，用于判断题目难度是否匹配 | `KG` / `PRIMARY_LOW` |
| `ts` | 事件发生时间（毫秒时间戳） | `1763107200000` |

事件含义：

- `activate`：该安装首次启动 App，仅上报一次；
- `day_open`：当天第一次打开 App，每天最多一条；
- `quiz_done`：完成一次普通练习或今日 Loop；
- `diagnostic_done`：完成一次 12 题摸底测评。

### 2.2 明确不采集的内容

- 孩子的姓名、头像、年级班级、学校等身份信息；
- 题目内容、孩子的作答内容、错题、得分、星星与奖励明细；
- 设备型号、系统版本、IMEI、Android ID、广告 ID、MAC 地址；
- 位置、通讯录、相册、通话记录、剪贴板；
- 任何可跨应用追踪或用于广告投放的标识。

`install_id` 是 App 自己生成的随机字符串，重装后会变化，不能用来识别设备，也不能与其他 App 关联。

### 2.3 用途

仅用于：统计启动量、日活、练习与测评完成量、学段分布，据此改进题库难度与产品流程。不用于广告、画像售卖或任何形式的用户追踪。

### 2.4 如何关闭

路径：**家长区 → 管理 → 说明 → 隐私政策 → 匿名使用统计**，关闭开关即可。

关闭后：

- 立即停止产生与发送新的统计事件；
- 本地已排队但未发送的事件会被清空；
- 不影响任何学习功能。

## 三、数据保留与删除

### 3.1 本地队列

待发送事件保存在本机数据库的独立表中，发送成功后立即删除；未发送成功的事件最多保留 30 天，或重试 3 次后自动丢弃。

### 3.2 接收端

统计接收端使用飞书多维表格的 Webhook 自动化（飞书，字节跳动旗下产品），只保存上述 6 个字段。明细数据保留 90 天，之后仅保留不含 `install_id` 的聚合统计。

### 3.3 删除请求

如需删除与你对应的统计记录，请在 GitHub Issues 中提交请求，并提供 App 内展示的 `install_id`（隐私政策页可直接看到）。我们会在核实后删除对应记录，整个过程不需要你公开真实身份。

## 四、网络访问说明

App 仅在以下两种情况下联网：

1. 发送上述匿名统计事件（默认开启，可关闭）；
2. 可选的 AI 反馈文案生成（当前版本未启用真实接口，全部走本地规则）。

孩子做题、判分、错题闭环、学习报告全部离线完成。

## 五、第三方与 SDK

- 不接入广告 SDK；
- 不接入第三方分析 SDK（统计由 App 直接发送到开发者配置的 Webhook）；
- 统计接收端为飞书多维表格（飞书，字节跳动旗下产品），仅接收第 2.1 节列出的字段；
- 除统计接收端外，**不向任何第三方共享、出售或转让**任何数据；
- 不进行数据出境传输，统计接收端部署在境内。

## 六、儿童个人信息保护

小步面向学龄前与小学低年级儿童，但**不收集任何可识别儿童身份的个人信息**。学段字段仅用于匹配题目难度，且由家长在本地设置。

- 未满 14 周岁的儿童应在监护人陪同下使用，并由监护人阅读本政策、代为做出统计开关的选择；
- 家长可随时关闭统计，或直接清除本地数据；
- 如监护人发现孩子在未经同意的情况下提供了个人信息，可通过 Issues 联系我们删除。

## 七、政策更新

本政策随版本更新。每次变更都会写入 App 内「更新记录」与项目 `CHANGELOG.md`；涉及采集范围扩大的重大变更，会在更新说明中明确提示。

## 八、开发者如何配置统计接收端

统计端点不是硬编码的，而是构建参数：

```bash
gradle :app:assembleRelease \
  -PtelemetryWebhook="https://open.feishu.cn/open-apis/bot/v2/hook/你的Webhook" \
  -Pchannel="feishu"
```

- 不传 `-PtelemetryWebhook` 时，App 不发送任何统计数据（等价于全局关闭）；
- 只接受 `https://` 地址，构建期会校验，避免明文传输；
- `-Pchannel` 用于区分分发渠道，默认 `dev`；
- 接收端在飞书多维表格中配置「自动化 → 接收到 Webhook 请求 → 新增记录」，按上述 6 个字段建列即可。

## 九、权限清单

App 仅申请以下权限，均与核心功能直接相关：

| 权限 | 用途 | 是否可拒绝 |
|---|---|---|
| `INTERNET` | 发送匿名统计（可在隐私政策页关闭）、可选的 AI 文案接口 | 可在系统层禁用网络，学习功能仍可用 |
| `ACCESS_NETWORK_STATE` | 判断当前是否有网络，避免无网时反复重试 | 同上 |

不申请录音、定位、通讯录、相册、存储、电话状态、广告标识等权限。App 已关闭云备份与设备间迁移，学习数据不会通过系统备份离开设备。
